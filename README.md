# Paquete 1 Template

Sistema de captación de prospectos desarrollado con Flask, Bootstrap y SQLite.

## Características

* Landing page profesional
* Formulario de contacto
* Captura de prospectos
* Panel administrativo
* Login protegido
* Integración con WhatsApp
* Eliminación de prospectos
* Registro de fecha de captura

## Tecnologías

* Python
* Flask
* SQLite
* Bootstrap 5
* HTML
* CSS

## Instalación

```bash
git clone https://github.com/Luis-Avelar/paquete1-template.git
cd paquete1-template

python3 -m venv venv
source venv/bin/activate

pip install -r requirements.txt

python3 app.py
```

Este proyecto funciona como plantilla base para pequeños negocios que necesitan:
